SLIDE 2: PROBLEM STATEMENT
============================================================
Cardiovascular diseases (CVDs) are the leading cause of death 
globally.

Given 13 clinical features, predict whether a patient has 
heart disease.

This is a BINARY CLASSIFICATION problem:
  - 0 = No Heart Disease
  - 1 = Heart Disease Present

============================================================
SLIDE 3: DATASET OVERVIEW
============================================================
Source: UCI Heart Disease dataset variant
Total Rows: 918 (cleaned to 902 after outlier removal)
Total Columns: 12 (11 features + 1 target)
Class Balance: ~55% Positive, ~45% Negative

FEATURES:
  Numerical (5):
  - Age                    (int)
  - RestingBP              (int)  — Resting blood pressure
  - Cholesterol            (int)  — Serum cholesterol
  - MaxHR                  (int)  — Maximum heart rate achieved
  - Oldpeak                (float) — ST depression induced by exercise

  Categorical (6):
  - Sex                    (M/F)
  - ChestPainType          (ATA / NAP / TA / ASY)
  - FastingBS              (0 or 1)  — Fasting blood sugar > 120 mg/dl
  - RestingECG             (Normal / ST / LVH)
  - ExerciseAngina         (Y / N)
  - ST_Slope               (Up / Flat / Down)

Target:
  - HeartDisease           (0 = No, 1 = Yes)

============================================================
SLIDE 4: DATA PREPROCESSING PIPELINE
============================================================
Step 1: Missing Values Check
  - None found (0 missing values)

Step 2: Duplicate Check
  - None found

Step 3: Outlier Removal (3-Sigma Method)
  Removed extreme values beyond 3 standard deviations:
  - Cholesterol:  3 rows removed
  - Oldpeak:      6 rows removed
  - RestingBP:    7 rows removed
  Final shape: 902 rows x 12 columns

Step 4: Label Encoding
  - ExerciseAngina:  N → 0, Y → 1
  - ST_Slope:        Down → 1, Flat → 2, Up → 3
  - RestingECG:      Normal → 1, ST → 2, LVH → 3

Step 5: One-Hot Encoding (drop_first)
  - Sex → Sex_M (1 if Male, 0 if Female)
  - ChestPainType → ChestPainType_ATA, _NAP, _TA (ASY is baseline)

Step 6: Train/Test Split
  - 80% Train (721 samples)
  - 20% Test (181 samples)

Step 7: Feature Scaling
  - StandardScaler applied

Step 8: Dimensionality Reduction
  - PCA with 7 components (~85% explained variance)

============================================================
SLIDE 5: PCA — PRINCIPAL COMPONENT ANALYSIS
============================================================
Purpose: Reduce feature dimensions from 13 to 7 while 
         retaining ~85% of the variance

Why PCA?
  - Removes multicollinearity between features
  - Reduces overfitting risk
  - Speeds up training
  - Retains most of the information

Components: 7 principal components
Explained Variance: ~85%
Trade-off: Slight accuracy loss (86.19% → 84.53%) for better
           generalization and faster inference

SLIDE 12: COMPARISON — PCA vs RAW FEATURES
============================================================
Condition A: Raw 13 Features + Random Forest (no PCA)
  - Accuracy: 86.19%
  - F1-Score: 86.13%

Condition B: PCA (7 components) + Logistic Regression
  - Accuracy: 84.53%
  - F1-Score: 84.52%

Difference: -1.66% accuracy
Trade-off accepted: Slight accuracy drop for:
  - Reduced dimensionality (13 → 7)
  - Better generalization
  - Faster inference
  - More interpretable model

SLIDE 15: RESULTS & KEY FINDINGS
============================================================
1. Best Model: Logistic Regression (84.53% accuracy)
   with confidence scores averaging ~88.8%

   retaining ~85% variance with minimal accuracy loss

   there's a trade-off between dimensionality reduction

   confidence scores AND batch CSV processing

============================================================
SLIDE 16: LIMITATIONS
============================================================
1. Dataset size (902 samples) limits generalization to 
   broader populations

2. PCA reduces interpretability of individual feature 
   contributions (can't easily explain "why" a prediction 
   was made)

3. Model not validated on external/independent datasets

4. No handling of temporal or longitudinal patient data
   (only single-visit snapshot)

5. No deep learning exploration

6. Class imbalance (~55/45) not severe but not addressed
   with weighting or resampling

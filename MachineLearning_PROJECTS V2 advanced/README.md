## Quick Start

1. Open a project folder from the index above.
2. If a README exists, follow its setup instructions.
3. If a requirements file exists, install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the entry file listed in the project index.

## Conventions

- Python projects typically use `main.py` or a task-specific script.
- Java projects include a `Main.java` entry.
- NLP and model-training projects may include notebooks and checkpoints.

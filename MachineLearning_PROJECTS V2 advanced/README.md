================================================================================
MACHINELEARNING PROJECTS V2 (ADVANCED)
================================================================================

A curated set of advanced machine learning projects covering NLP, computer vision,
audio and speech, and structured data pipelines. Every project lives in its own
folder with runnable scripts, experiments, or notebooks.

-------------------------------------------------------------------------------
CORE HIGHLIGHTS
-------------------------------------------------------------------------------
- Multi-domain coverage: NLP, CV, audio/speech, structured data
- Mix of research-style experiments and applied pipelines
- Standalone folders with training, evaluation, and inference code

QUICK START (GENERAL)
-------------------------------------------------------------------------------
1. Open a project folder from the index above.
2. If a README exists, follow its setup instructions.
3. If a requirements file exists, install dependencies:

	pip install -r requirements.txt

4. Run the entry file shown for that project.

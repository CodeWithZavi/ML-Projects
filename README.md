## Quick start

1. Pick a folder from the repository map.
2. Read that folder's README (if present).
3. Install dependencies if a requirements file exists.
4. Run the entry script shown in the folder README.

## Conventions

- Python projects usually use main.py or a task-specific script.
- Java projects use Main.java.
- Some projects include notebooks for exploration or evaluation.
